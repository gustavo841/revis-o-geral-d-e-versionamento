Questão 2 — Verdadeiro (V) ou Falso (F)
Copie as afirmações para o seu 
README.md e marque (V) ou (F) em cada uma: 
• ( F ) O Git e o GitHub são exatamente a mesma coisa. 
• ( F  ) O comando git pull serve para apagar um repositório da nuvem. 
• ( V ) Trabalhar em branches separadas evita que um erro quebre o código principal (
main ). 
• ( V  ) Uma boa mensagem de commit deve explicar de forma clara o que foi alterado no código.
